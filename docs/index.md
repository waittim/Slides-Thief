# Slides Thief documentation

Slides Thief straightens photographed presentation slides, corrects perspective distortion, and combines the corrected images into a PDF. Use the browser app for an interactive workflow that does not upload source photos, or the Python CLI for reproducible batch processing. See [Privacy](privacy.md) for the separate website analytics behavior.
